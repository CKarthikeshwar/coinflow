← Overview

Midnight

The reference look, black and white. Dark, no accent, no semantic colour — the interface reads as a native iOS finance app and gets out of the way.

Mode

Operate — task completion, scanability, native affordances first.

Palette

Black / white / grey. That is the whole palette.

Type

Manrope on headings + figures, Geist on UI text. Tabular-nums for every amount.

Direction cue

The +/− sign, always present, plus weight — never colour.

Hero

Balance = Income − Spent for the month; Income + Spent shown as components. No “so far”.

Card label

The Note → falls back to the Account → “No note”. The Account also drives account → category memory (F8).

Layout

Card-based (1.png/3.png): each transaction is its own card with a category icon tile. Icons = Lucide (the sprite here is hand-traced Lucide).

Screens

One file per phase. screens.html — the tab / flow screens (Add has two states: amount, and text-field with the system keyboard). p0-screens.html — the P0 detail screens. p1-screens.html — onboarding, Categories, Settings + subpages, and the global states.

The notification

The core loop. Known account → Save / Add / Discard; new account → Add / Discard. No confidence score — the user just discards or adds.

Colour

The Analytics “Where it went” breakdown uses a ~9-hue category palette (dot / bar / donut) — nowhere else. V-11 carve-out.
