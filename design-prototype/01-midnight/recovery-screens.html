Recovery screens

A screen that doesn’t exist yet anywhere — not in code, not in SPEC-UI-UX.md. The root error boundary (§32.3 / E20): what a user sees if CoinFlow hits an uncaught render crash. It pairs with this session’s Sentry work — once armCrashReporting is on, a real crash now actually reports somewhere, so it’s worth deciding what the recovery moment itself looks like. Three tonal/information variants below, not yet chosen. Same copy baseline as §32.4’s existing table (“Something went wrong.” → Reload app), stretched three different ways.
