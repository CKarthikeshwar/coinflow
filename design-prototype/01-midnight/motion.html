Motion

The key transitions from SPEC-UI-UX.md §3.5, running — timing tokens fast 120 / base 200 / slow 320 ms and the three easing curves. This is the only prototype page with JavaScript; it exists to preview motion, not to be pixel-final. Each frame autoplays once; press Replay to see it again. The page honours the OS Reduce Motion setting (slides and scale collapse to a fade / cut). The RN build implements these with react-native-reanimated v4 and tunes them on-device.
