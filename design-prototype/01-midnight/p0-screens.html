P0 core screens

Transaction Confirmation (detected-txn review, with the custom numeric keypad), Transaction Details, Edit Transaction, and the Category picker sheet — all four in this one file. Dark only. The in-app keypad is amount-only and the action button docks below it; Account / Note / Description use the system keyboard, and the amount collapses to a slim bar once you scroll to the fields. The raw SMS is never shown or stored; a detected transaction carries only a quiet provenance line. SPEC §6.4 / 6.8 / 6.6 / §8.
